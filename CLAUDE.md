# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Androme fork of [openid/AppAuth-Android](https://github.com/openid/AppAuth-Android) — a client SDK for OAuth 2.0 and OpenID Connect on Android. Tracks `upstream/device_grant` (the `solevic` fork adding RFC 8628 Device Authorization Grant) plus Androme-local changes on `master`. Pure Java, no Kotlin. `WebView` is intentionally unsupported; authorization uses Custom Tabs.

Two Gradle modules:
- `:library` — the published SDK (`net.openid:appauth`, package `net.openid.appauth`).
- `:app` — demo app (`net.openid.appauthdemo`), not published.

## Commands

Run from repo root via the wrapper (`./gradlew`, Gradle 8.5, JDK 17, AGP 8.0.1).

```bash
./gradlew :library:assembleRelease        # build the SDK AAR
./gradlew :app:assembleDebug              # build demo app
./gradlew :library:testDebugUnitTest      # run library unit tests (Robolectric)
./gradlew check                           # full check: tests + checkstyle (warnings-as-errors)
./gradlew :library:jacocoTestReport       # coverage report -> library/build/reports/jacoco
./gradlew showVersion                     # print git-derived version info
```

Run a single test class / method:

```bash
./gradlew :library:testDebugUnitTest --tests "net.openid.appauth.IdTokenTest"
./gradlew :library:testDebugUnitTest --tests "net.openid.appauth.IdTokenTest.testFrom_simpleIdToken"
```

Checkstyle is enforced and **fails the build on any warning** (`config/style.gradle` → `failOnCheckstyleWarning`, wired into `check`). Android lint also runs with `warningsAsErrors true`. Run `./gradlew check` before considering work done.

## Layout quirks (non-standard Gradle)

Source layout is overridden in `config/android-common.gradle`, not the default `src/main/java`:
- Production sources live in `library/java/` and `app/java/` (package roots directly under `java/`).
- Tests live in `library/javatests/` (mapped to the `test` source set).
- Manifests are at module root: `library/AndroidManifest.xml`, `app/AndroidManifest.xml`.

Shared build logic lives in `config/*.gradle`, applied into each module: `android-common.gradle` (source sets, SDK levels, lint), `style.gradle` (checkstyle), `coverage.gradle` (jacoco), `testdeps.gradle` (test deps), `javadoc.gradle` (md-doclet javadoc), `keystore.gradle`.

Version (`versionName`/`versionNum`) is derived at configure time from git via grgit (`build.gradle`): name = `git describe`, num = commit count. Falls back to `DEV`/`1` outside a git checkout.

SDK levels: `minSdk 16`, `compile/targetSdk 33`. `appauth.keystore` (password `appauth`, committed) signs both debug and release demo builds; auto-generated by `keystore.gradle` if absent.

## Library architecture

The SDK maps OAuth2/OIDC request and response objects 1:1 to spec, then drives them through one service class.

- **`AuthorizationService`** — the engine. Dispatches browser-based authorization (`performAuthorizationRequest`, launches Custom Tab → `AuthorizationManagementActivity`) and HTTP-based token/registration/device requests (`performTokenRequest`, `performRegistrationRequest`, `performDeviceAuthorizationRequest`). Must be `dispose()`d.
- **`AuthState`** — serializable container for the whole authorization session (config + last auth/token responses + refresh token). Persist as JSON via `jsonSerializeString()` / `jsonDeserialize()`. `performActionWithFreshTokens()` is the main entry point for getting a usable access token, refreshing if needed.
- **`AuthorizationServiceConfiguration`** — endpoint set; can be built manually or fetched from an OIDC discovery document (`fetchFromIssuer`).
- **Request/Response pairs** model each flow: `AuthorizationRequest`/`Response`, `TokenRequest`/`Response`, `RegistrationRequest`/`Response`, `DeviceAuthorizationRequest`/`Response` (RFC 8628), `EndSessionRequest`/`Response`. Each has a `Builder` and round-trips to/from JSON.
- **`ClientAuthentication`** strategies: `ClientSecretBasic`, `ClientSecretPost`, `NoClientAuthentication`.
- **Browser handling** (`browser/`): `BrowserMatcher` / allow-deny lists select which browser receives the auth request; Custom Tabs preferred.
- **Activity glue**: `AuthorizationManagementActivity` (manages the browser round-trip, survives config changes) and `RedirectUriReceiverActivity` (catches the redirect URI).
- **`internal/`**: `Logger`, `UriUtil`; **`connectivity/`**: `ConnectionBuilder` abstraction for HTTP.

Extension parameters: every request/response accepts `additionalParameters`, validated against reserved keys by `AdditionalParamsProcessor` — the mechanism for handling non-standard provider params.

## Androme-local changes vs upstream

Changes on `master` beyond `upstream/device_grant` (see `git log` / `git diff upstream/device_grant master`):
- `AuthState`: username/password no longer stored in serialized state.
- `AuthorizationService` / `TokenRequest`: `client_secret` added to token request params.
- Broadened exception handling (catch-all incl. `IllegalArgumentException`) in auth-management paths to avoid app crashes on malformed redirects/responses.
- `IdToken` / `JsonUtil`: extended ID token parsing.

When editing library code, keep diffs minimal and upstream-mergeable — this is a tracking fork.

## Demo app

`app/java/net/openid/appauthdemo/`: `LoginActivity` (starts auth) → `TokenActivity` (exchanges code, calls userinfo). `AuthStateManager` persists `AuthState` in SharedPreferences; `Configuration` reads `app/res/raw/auth_config.json` (the provider/client config to edit when testing). `appAuthRedirectScheme` manifest placeholder is set in `app/build.gradle`.
